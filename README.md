# Soccer Performance Analytics Platfrom 

This is going to be a fullstack application that tracks player performances across matches, has a built in annotating function, analyzes player statistics, and will build predictive modeling from player and team data

# Goals

This project is built to assist coaches in,

- Tracking Player Performance over time
- Noticing Trends in a Teams performance
- Grading whether a player is adhering to the gameplan established
- Making a model that will predict a result 
    - using the models result, I will change the features to find what will be required to turn that result to a win
